# Visualizing the History of Nobel Prize Winners

## Overview
The Nobel Prize has been among the most prestigious international awards since 1901, awarded annually across Chemistry, Literature, Physics, Physiology or Medicine, Economics, and Peace. This project performs an exploratory data analysis (EDA) using Python, pandas, and seaborn on historical Nobel Prize data (1901–2023) to examine trends in award distribution, demographic shifts, top winning countries, and gender ratios over time.

## Key Objectives
* **Demographic Trends:** Analyze the distribution of award winners by gender and birth country over time.
* **Dominant Categories & Nations:** Identify which countries and prize categories have accumulated the most Nobel laureates.
* **Historical Variations:** Visualize how winner demographics and age groups have evolved across different decades.
