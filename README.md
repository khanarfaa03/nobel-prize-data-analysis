# Visualizing the History of Nobel Prize Winners

## Overview
The Nobel Prize has been awarded annually since 1901 across Chemistry, Literature, Physics, Physiology or Medicine, Economics, and Peace[span_6](start_span)[span_6](end_span). This project explores a dataset from the Nobel Prize API (1901–2023) to uncover patterns in award distribution, country dominance, gender gaps, and age trends over time[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
